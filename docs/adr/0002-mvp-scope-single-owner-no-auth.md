# Границы MVP: один владелец, без авторизации

Сервис рассчитан на одного владельца на весь инстанс, админка доступна без логина — в сценарии из README входа нет, а для учебного проекта авторизация не добавляет ценности. Объём MVP — ровно сценарий из README (шаги 1–13): сознательно не делаем отмену и перенос записи, нескольких владельцев, напоминания и интеграцию с внешними календарями. Это граница скоупа, а не техническое ограничение: при появлении этих функций решение пересматривается.
