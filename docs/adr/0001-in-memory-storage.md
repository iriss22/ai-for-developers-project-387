# Хранение данных в памяти, без базы данных

Учебный проект, и для MVP персистентность между запусками не нужна. Решили хранить все данные (типы встреч, записи) в in-memory репозиториях внутри Spring-приложения, без базы данных: это убирает инфраструктуру и миграции из критического пути. Цена решения: все данные теряются при перезапуске. Переход на настоящую БД — осознанно отложенное отдельное решение; репозитории с самого начала прячем за интерфейсами, чтобы оно было дешёвым.
