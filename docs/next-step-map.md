# Карта следующего шага

Открытые вопросы по функциям за пределами главной страницы. Решения по ним не принимаем заранее — это фронтир для следующих раундов проектирования.

## Бронирование

- Модель слотов: как слоты генерируются из длительности типа встречи и окна записи (14 дней, 9:00–18:00)?
- Пересечения: как помечаются «Занято» слоты разных типов встреч, пересекающиеся по времени?
- Жизненный цикл записи: какие состояния есть у записи и какие переходы допустимы?
- Часовой пояс: в чьём поясе задано окно 9:00–18:00 и как показывать время гостю?

## Данные

- Seed-данные: откуда берутся типы встреч при пустом хранилище (в README фигурирует «Встреча 30 минут»)?
- Миграция с in-memory на базу данных (см. ADR-0001).

## Админка

- CRUD типов встреч: редактирование и удаление, что происходит с существующими записями?
- Список предстоящих встреч: состав полей, сортировка, пагинация.

## API

- Форма эндпоинтов и форматы запросов/ответов для бронирования и админки.
